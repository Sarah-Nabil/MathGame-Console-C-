# 🎮 Math Game – C++ Console Application

A fun and interactive **console-based Math Game** developed using **C++**.  
The game generates random math questions based on the selected difficulty level and arithmetic operation, then evaluates the player's performance.

---

## ✨ Features

- 🎯 **Multiple Difficulty Levels:** Easy, Medium, Hard, or Mixed.
- ➕ **Arithmetic Operations:** Addition, Subtraction, Multiplication, Division, or Mixed Operations.
- 🎲 **Random Questions:** Generates questions dynamically during gameplay.
- ✅ **Answer Validation:** Checks answers and provides immediate feedback.
- 📊 **Score Tracking:** Keeps track of correct and incorrect answers.
- 🏆 **Game Results:** Determines whether the player passes or fails based on their performance.
- 🎨 **Console Feedback:** Uses console colors to distinguish correct and incorrect answers.
- 🔄 **Play Again:** Allows players to start another round without restarting the application.

## 🛠️ Technologies & Concepts

- **Language:** C++
- **Programming Concepts:**
  - Functions and Structures (`struct`)
  - Enumerations (`enum`)
  - Conditional Statements (`if`, `switch`)
  - Loops
  - Random Number Generation
  - Basic Input and Output

## 🎮 How to Play

1. Run the application.
2. Choose your preferred difficulty level.
3. Select an arithmetic operation.
4. Answer the generated math questions.
5. Review your score and final result.
6. Choose whether to play again.

## 🚀 Getting Started

### Prerequisites

- A C++ compiler, such as GCC or MSVC.
- Visual Studio or another C++ development environment.

### Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/Sarah-Nabil/MathGame-Console-C-.git
   ```

2. Open the project in Visual Studio or your preferred C++ IDE.
3. Build and run the application.
